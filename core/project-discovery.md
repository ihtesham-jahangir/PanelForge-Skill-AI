# Project Discovery

Before implementation, inspect:

1. Repository root, Git status, and uncommitted changes.
2. README, contributor instructions, agent instructions, and deployment docs.
3. Package manifests, lockfiles, runtime versions, and environment configuration.
4. Source structure, routes, models, API clients, design tokens, and reusable components.
5. Existing tests, fixtures, CI workflows, linters, formatters, and type checks.
6. Authentication, authorization, tenant boundaries, logging, and error conventions.

Record findings in the task or project report. Do not overwrite existing work, introduce a parallel stack without justification, or infer a dependency from an import alone.

## Discovery output

- Existing stack and versions.
- Relevant entry points and extension seams.
- Reusable components and helpers.
- Required behavior and non-functional constraints.
- Known risks, blockers, and commands used for verification.
