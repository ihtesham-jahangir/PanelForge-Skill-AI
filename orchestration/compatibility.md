# Compatibility and Conflict Resolution

PanelForge is the fallback baseline. Specialist recommendations are advisory and must be checked for:

- Explicit user requirements.
- Existing project conventions.
- Security, privacy, authorization, and data integrity.
- Accessibility and responsive behavior.
- Tool and runtime compatibility.

When recommendations conflict, apply this order: user instruction, security/privacy, correctness, accessibility, existing architecture, agreed design system, specialist guidance, internal defaults.

Agent-specific notes are in [`../adapters/claude-code.md`](../adapters/claude-code.md), [`../adapters/codex.md`](../adapters/codex.md), [`../adapters/cursor.md`](../adapters/cursor.md), [`../adapters/windsurf.md`](../adapters/windsurf.md), [`../adapters/copilot.md`](../adapters/copilot.md), and [`../adapters/generic.md`](../adapters/generic.md).
