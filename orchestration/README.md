# Specialist Orchestration

PanelForge may use specialist skills or tools when the current agent environment exposes them. Discovery is evidence-based:

1. Inspect the environment's actual skill/tool registry.
2. Read the specialist's current entry instructions and official installation documentation.
3. Check license, compatibility, dependencies, and invocation syntax.
4. Invoke only when relevant to the request.
5. Reconcile output against user requirements, existing architecture, security, and accessibility.
6. Record the result as installed, available, unavailable, skipped, or unverified.

If a specialist is unavailable, use the corresponding PanelForge module as a fallback. Never copy a third-party repository wholesale or claim installation from a URL alone.
