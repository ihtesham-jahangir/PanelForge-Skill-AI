# Skill Discovery Record

The initial repository baseline did not expose a coding-agent skill registry, so no third-party skill is marked installed. The following official sources are candidates for environment-specific verification:

- UI UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- gstack: https://github.com/garrytan/gstack
- Playwright: https://playwright.dev/
- axe-core: https://github.com/dequelabs/axe-core
- Lighthouse: https://developer.chrome.com/docs/lighthouse/
- OWASP ZAP: https://www.zaproxy.org/

Initial source inspection confirmed that Playwright documents an auto-waiting test runner, cross-browser execution, accessibility snapshots, and an MCP server; ZAP describes itself as a free, open-source web application scanner; and axe-core is distributed as an accessibility engine/package. These observations support their recommended categories but do not constitute installation or project execution evidence.

Before using any candidate, inspect its current entry file, installation instructions, license, dependencies, supported agents, and invocation syntax. Record the observed version and command in the delivery report.
