# Security Review

1. Confirm scope and authorization.
2. Map assets, actors, trust boundaries, tenant boundaries, and sensitive actions.
3. Review authentication, authorization, input/output handling, sessions, uploads, rate limits, secrets, logging, and dependencies.
4. Execute safe positive/negative authorization tests in an authorized environment.
5. Rank findings by severity and confidence, remediate, and add regression tests.
6. Block release for unresolved critical authorization, tenant-isolation, data-integrity, or secret exposure issues.
