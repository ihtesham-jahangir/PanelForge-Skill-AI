# Style Combinations

Safe combinations are deliberate: Flat Design + Bento Grid, Material You + Data-dense Enterprise, Swiss Style + Editorial, or Minimalism + Aurora accents. Avoid combining Neumorphism with high-density tables, Glassmorphism with low-contrast text, or multiple competing motion/glow systems.

Document the primary style, secondary influence, reason, token ownership, and accessibility fallback in the design specification. If a combination cannot be explained in one sentence, keep one style.
