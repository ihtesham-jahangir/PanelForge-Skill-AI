# Engineering Modules

These modules define implementation contracts independent of framework:

- [`api.md`](./api.md): API contracts, validation, errors, and idempotency.
- [`backend.md`](./backend.md): service boundaries, jobs, integrations, and observability.
- [`frontend.md`](./frontend.md): feature slices, state, forms, and accessibility.
- [`data.md`](./data.md): persistence, migrations, and transaction boundaries.

Load the framework-specific guidance only after repository discovery. Existing project conventions take precedence.
