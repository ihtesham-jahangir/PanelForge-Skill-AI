# Release Checklist

- [ ] Requirements and acceptance criteria reviewed.
- [ ] Unit, integration, API, and relevant E2E tests executed.
- [ ] Authorization, ownership, tenant isolation, and sensitive actions verified.
- [ ] Migrations reviewed and backup/rollback plan tested.
- [ ] Accessibility, responsive, visual, and performance checks executed.
- [ ] Logs, metrics, alerts, and error handling reviewed.
- [ ] Dependencies and secrets checked.
- [ ] Deployment and rollback steps documented.
- [ ] Known limitations and residual risks approved.
- [ ] Capability matrix completed with `implemented`, `unverified`, `blocked`,
      or `requires-human-decision` for every scoped area.
- [ ] External credentials, provider webhooks, cloud resources, and production
      configuration explicitly verified or marked unverified.
- [ ] Final implementation report lists completed work and known non-generated
      work; no unsupported production, security, compliance, or integration
      claims remain.
