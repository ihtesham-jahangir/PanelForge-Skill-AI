# Security Policy

PanelForge is a documentation and agent-customization skill, not a hosted service. Do not include credentials, tokens, private source, or production data in issues, examples, prompts, fixtures, or reports.

Report a security concern privately to the repository owner before public disclosure. Include the affected file, impact, reproduction conditions using authorized test data only, and a minimal remediation suggestion. Do not submit destructive payloads or test systems you do not own or have permission to assess.

Security guidance is maintained in [`modules/security.md`](./modules/security.md). Any change affecting authorization, tenant isolation, secrets, hooks, or external commands requires targeted verification and explicit documentation of residual risk.
